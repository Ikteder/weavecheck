## Implementation observations

- Including actor locals in the state key is required. Omitting them would merge executions that later write different values.
- Lock acquisition is disabled while another actor owns the lock. This makes a no-enabled-actor state a direct deadlock signal for unfinished scripts.
- State deduplication intentionally reports unique reachable outcomes, not schedule probabilities.
- Model data is escaped before embedding into HTML because a model name can contain markup.
- The first public CI run showed that an unsafe demo cannot be chained directly into a success-only package script. Verification now asserts the expected unsafe result and exact metrics without changing the CLI's nonzero unsafe exit.
