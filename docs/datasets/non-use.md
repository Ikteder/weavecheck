# Dataset Card: no external dataset

Date: 2026-09-09

WeaveCheck does not train, fit, or benchmark against an external dataset. Its three fixtures are hand-authored synthetic concurrency models distributed under the repository license.

The fixtures demonstrate a lost update, a lock-protected repair, and opposite lock ordering. They are regression inputs, not evidence about defect prevalence in real software. No personal, proprietary, scraped, or licensed third-party data is included.
